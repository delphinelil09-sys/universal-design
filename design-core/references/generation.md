# Generation — The "0 to 1" Process

Used in **creation mode**. The user has a brief and (in Phase 2) an idea plus a reference. This is the process that turns that into a site.

Movement is top-down through the four layers. Each layer's decisions constrain the next.

## Frame — composition and space

Decide first. This is the strongest layer, and everything else depends on it.

- **Reading order** — what does the eye see 1st, 2nd, 3rd? Name it explicitly.
- **Grid** — one system (12-column, asymmetric, editorial). Applied everywhere.
- **Gaze path** — the shape the eye follows: F, Z, vertical, diagonal. Chosen, not accidental.
- **Rhythm** — where the page breathes wide and where it tightens. Air is a working element, not leftover space.
- **Focal anchor** — the one thing the composition is built around.

The frame is done when you can describe the page's gesture in one sentence.

## Body — form and color

Decide second. Shapes and tone that live inside the frame.

- **Silhouette logic** — what shape language does this site speak? Sharp edges, soft radii, organic curves, mixed? One logic, applied consistently.
- **Radius system** — one token (or one system of two), not scattered values.
- **Color tokens** — 4–6 named values: background, surface, text, muted text, accent, accent-contrast.
- **Distribution** — 60-30-10: dominant, secondary, accent.
- **Contrast** — every pair checked before committing.

The body is done when the site has a tone you can name.

## Surface — texture and typography

Decide third. How it feels on contact.

- **Typeface(s)** — one family, or two clearly distinct. Chosen for the subject, not the default.
- **Type scale** — explicit steps, not random sizes. Weights and letter-spacing set deliberately.
- **Line length** — ≤80 characters for body; serif may run slightly longer with more line-height.
- **Texture** — if used, supports depth. Grain, photographic material, paper feel — chosen, not decorated with.
- **Shadow policy** — one policy: none, hard, soft, layered. Applied consistently.

The surface is done when the site has a voice.

## Accent — point and line

Decide last. The smallest details.

- **Icons** — one weight and style. Aligned to the type baseline.
- **Dividers and rules** — used only when they encode structure, not as decoration.
- **Micro-states** — hover, active, focus, disabled. Consistent across the site.
- **The one memorable detail** — one thing the eye remembers after leaving. One, not five.

The accent is done when the site has a signature.

## How "why" changes priorities

The goal established at entry reshapes which layers dominate.

**Goal = sale (marketing leads).** The frame is dominated by the gaze path and the CTA. The body serves trust (calm colors, clear buttons). The surface keeps typography plain and readable. The accent is minimized so the CTA is the strongest element. Air works for focus, not for beauty.

**Goal = impression (design leads).** The frame is built around the work or the subject. The body is restrained so the work provides the color. The surface carries much of the character (typography as part of the gesture). The accent is minimal, so it does not argue with the work.

**Goal = explanation (design serves clarity).** The frame is a reading grid (65–75 chars per line). The body uses color for trust. The surface is where most of the work happens — typography does the heavy lifting. The accent is nearly absent.

## What generation does not do

It does not run without an idea and a reference in Phase 2. It does not add character to a site that failed Phase 1. It does not improvise a concept — it executes one the user brought.
