# Copy — Words as a Design Element

The words on a site are an element of the design, not a layer over it. A page with a perfect grid and "Empower your workflow" still reads as generated — the text is the most common tell of the AI look.

This reference is not a copywriting guide. It is a filter: it keeps audit and generation from passing textual slop.

## What marks the template voice

Cut or rewrite when you see these — in audits, hunt them; in generation, never produce them:

- **Fish headlines** — "Transform the way you…", "Unlock the power of…", "Elevate your…". They name no object, no audience, no result. A headline that survives deleting every adjective is working; one that dies is fluff.
- **Subtitle that restates the headline.** The headline promises, the subtitle must sharpen — not repeat with more words.
- **Emoji in lists as decoration.** An emoji per bullet is a template smell, not a voice.
- **Middle-dot meta strings** — "Strategy · Design · Development". A marker of generated pages (see also `trends-2026-Q3.md`).
- **The empty value trio** — "Quality. Innovation. Passion." in a "why us" section. These words carry no information; replace them with the actual difference.
- **Benefitless CTAs** — "Learn more", "Get started" with no consequence. Say what happens: "Start free — no card", "See it in 2 minutes".
- **Adjectives instead of facts** — "ultra-fast" vs "0.4s response", "best-in-class" vs a benchmark, "enterprise-grade" vs the compliance names behind it.
- **Named-dropping without context** — logos, numbers, testimonials that appear without stating what they prove. Proof without its meaning is decoration.
- **"We are" instead of "you get"** — the site describes the company where the visitor expects their own outcome.

## The reality test

For any headline, subhead, CTA, or bullet:

1. Does it name an **object**, a **result**, or an **audience**? If none — rewrite.
2. Would a competitor's site fit this sentence unchanged? If yes — it is filler; write what is true for this site.
3. Can a number, a name, or a consequence replace an adjective? Do it.

## How it works in the two modes

- **Audit:** read the text through the same grid as the visuals — headlines, bullets, CTAs, links, labels. Textual slop is a Phase 1 finding exactly like a spacing violation: objective, fixable. Where the fix needs product facts, ask instead of inventing — facts are never fabricated.
- **Creation:** write the words together with the visuals, not after. Decide the promise per screen before the layout, so the composition carries the line and not vice versa.
