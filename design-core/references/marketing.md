# Marketing — The Filter Layer

Marketing is not a ninth element. It is a **filter layer** that sits over the design layers when the goal is sale, signup, or conversion.

## What "filter" means

The design layers (frame → body → surface → accent) stay exactly as they are. Marketing does not replace them and does not sit inside them. Every design decision is additionally checked against one question:

> **Does this work on conversion?**

If yes — keep it. If no — the goal decides who wins. This is not "design always wins" and not "marketing always wins."

## Vocabulary

- **First screen as promise** — within 3 seconds, the visitor must understand: what this is, who it's for, and why it matters. If the first screen doesn't promise, nothing below it matters.
- **Gaze path** — the sequence the eye follows. On a conversion page it moves promise → proof → action. If the path is broken, the CTA is invisible even when it's there.
- **CTA** — one primary action, visually dominant. Secondary actions are visibly subordinate. Tertiary actions (like "learn more") never compete with primary.
- **Proof** — testimonials, numbers, logos, screenshots, results. Placed where the visitor hesitates, not buried at the bottom.
- **Objection handling** — the reasons someone might not act (price, trust, timing, complexity). Addressed explicitly, in the interface's voice.

## Conflict rule

Design says "more air." Marketing says "button higher." Both are legitimate. **The goal decides.**

- If the goal is sale and the floor is intact → marketing wins on this specific conflict. The button moves up.
- If the goal is impression → design wins. The air stays.
- If the goal is explanation → they cooperate. The button moves up *and* the surrounding layout adjusts so the air isn't lost.

The rule is not a hierarchy. It is a resolution procedure: name the conflict, name the goal, decide, and say which one won and why.

## What marketing never overrides

The accessibility floor. Contrast, click zones, focus, body size — none of these are negotiable in the name of conversion. A button that "converts better" but fails contrast for a low-vision user is not a conversion win. It is a broken page.

## When marketing is not active

If the goal is impression or pure explanation, marketing does not run as a filter. The design layers proceed on their own. The vocabulary above may still inform the work — a portfolio still needs a clear path to contact — but it does not check every decision.
